# THRULALA 🦅

<a href="https://tabookot.github.io/thrulala/" style="display: inline-block; padding: 10px 24px; font-size: 16px; font-weight: bold; color: #ffffff; background-color: #1d9bf0; text-decoration: none; border-radius: 8px;">🚀 Открыть THRULALA</a>

> Эмулятор абсолютной политической правды. Создает самые величайшие, победоносные и эпичные посты, которые вы когда-либо видели. Никто не делает их лучше!

Это одностраничное веб-приложение генерирует абсурдные, но грамматически правильные пафосные посты в стиле электоральной риторики. В генератор вшиты типичные речевые обороты, названия стран, имена действующих политиков и фирменный эпический пафос.

Авторский коллектив — GLM, Kimi, Gemini.

## 🇺🇸 Особенности

* **Мультиперсонажность:** Лента объединяет сразу несколько колоритных деятелей. Новые посты генерируются случайно от лица любого из них.
* **Реалистичная накрутка:** Боты-фермы и алгоритмы X непрерывно накручивают лайки, огоньки, черепа и какашки. Скорость накрутки зависит от реального количества подписчиков прототипа!
* **Мультиязычность:** Интерфейс поддерживает английский, китайский и русский языки. Если локаль персонажа отличается от вашей, под постом появится кнопка «Перевести».
* **18+ Капча:** Полностью автономная капча, нарисованная через Canvas API. Чтобы войти, нужно поставить галочку, подтверждающую вашу готовность к разочарованиям, и ввести «кодовое слово взрослого человека».
* **Авто-генерация и авто-очистка:** Лента живет своей жизнью — сама генерирует посты и аккуратно растворяет старые (лимит 50 штук), чтобы не перегрузить ваш девайс.
* **Премиальный дизайн:** Темный фон в стиле X (Twitter) / Threads, плавные анимации появления, растворения и ядерного взрыва при очистке ленты.
* **Без зависимостей:** Чистый HTML, CSS и Vanilla JavaScript. Никаких `npm install`.

## 🚀 Как запустить локально

1. Скачайте репозиторий (или клонируйте: `git clone https://github.com/tabookot/thrulala.git`).
2. Откройте файл `index.html` в любом современном браузере.
3. Пройдите капчу, нажимайте кнопку **Thru** и наслаждайтесь величайшими заявлениями.

## 🌐 Развертывание на GitHub Pages

Проект изначально адаптирован для размещения на GitHub Pages:

1. Загрузите файлы (`index.html`, `script.js` и папку `pers/` с персонажами) в репозиторий GitHub.
2. Перейдите в **Settings** репозитория.
3. В левом меню выберите раздел **Pages**.
4. В блоке *Build and deployment* выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`. Нажмите **Save**.
6. Через пару минут ваш Эмулятор будет доступен по ссылке `https://<ваш_ник>.github.io/thrulala/`.
