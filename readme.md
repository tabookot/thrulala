# THRULALA 🦅

`https://tabookot.github.io/thrulala/

> Эмулятор абсолютной политической правды. Создает самые величайшие, победоносные и эпичные посты, которые вы когда-либо видели. Никто не делает их лучше нас!

Это одностраничное веб-приложение генерирует абсурдные, но грамматически правильные пафосные посты в стиле электоральной риторики. В генератор вшиты типичные речевые обороты, названия стран, имена действующих политиков и фирменный эпический пафос.

Авторский коллектив — GLM 5.2 и Kimi K3.

## 🇺🇸 Особенности

* **Идеальная грамматика:** Алгоритм составляет предложения по схеме `[Вступление] + [Субъект] + [Глагол] + [Объект] + [Концовка]`, чтобы текст звучал максимально естественно.
* **Геополитический размах:** В базу добавлены Спящий Джо, Иран, Нетаньяху, Путин, Украина, фейковые новости и радикальные левые.
* **Премиальный дизайн:** Темный фон, золотые акценты и красные кнопки. Настоящий патриотический вайб.
* **Анимации:** Плавное появление каждого нового шедевра, очистка и реакции.
* **Без зависимостей:** Чистый HTML, CSS и Vanilla JavaScript. Никаких `npm install`.

## 🚀 Как запустить локально

1. Скачайте репозиторий (или клонируйте: `git clone https://github.com/tabookot/thrulala.git`).
2. Откройте файл `index.html` в любом современном браузере.
3. Нажимайте кнопку и наслаждайтесь величайшими заявлениями.

## 🌐 Развертывание на GitHub Pages

Проект изначально адаптирован для размещения на GitHub Pages:

1. Загрузите файлы (`index.html`, `script.js`) в репозиторий GitHub.
2. Перейдите в **Settings** репозитория.
3. В левом меню выберите раздел **Pages**.
4. В блоке *Build and deployment* выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`. Нажмите **Save**.
6. Через пару минут ваш Эмулятор будет доступен
