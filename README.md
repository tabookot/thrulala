## 🇺🇸 Features

* **Multi-character Feed:** The timeline combines several colorful figures at once. New posts are generated randomly on behalf of any of them.
* **Realistic Inflation:** Bot farms and X algorithms continuously inflate likes, fires, skulls, and poop reactions. The inflation rate depends on the real-world follower count of the prototype (Trump gets the maximum boost!).
* **Multilingual Support:** The UI supports English, Chinese, and Russian. If a character's base locale (e.g., Trump thinks in English) differs from yours, a "Translate" button will appear under the post.
* **18+ Canvas Captcha:** A completely standalone captcha drawn via the Canvas API. To enter, you must check a box confirming your readiness for disappointment and enter the "adult code word" (TAXES, MORTGAGE, 税收).
* **Auto-generation & Auto-cleaning:** The feed lives its own life — it automatically generates posts and gently dissolves old ones (limit of 50) so it doesn't overload your device.
* **Premium Design:** Dark background in the style of X (Twitter) / Threads, smooth animations for appearance, dissolving, and a nuclear explosion effect when clearing the feed.
* **Zero Dependencies:** Pure HTML, CSS, and Vanilla JavaScript. No `npm install` required.

## 🚀 How to Run Locally

1. Download the repository (or clone it: `git clone https://github.com/tabookot/thrulala.git`).
2. Open the `index.html` file in any modern browser.
3. Pass the captcha, hit the **Thru** button, and enjoy the greatest statements ever made.

## 🌐 Deployment on GitHub Pages

The project is initially adapted for hosting on GitHub Pages:

1. Upload the files (`index.html`, `script.js`, and the `pers/` folder with the characters) to your GitHub repository.
2. Go to the repository's **Settings**.
3. In the left menu, select the **Pages** section.
4. Under the *Build and deployment* block, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder. Click **Save**.
6. In a few minutes, your Emulator will be available at `https://<your_username>.github.io/thrulala/`.
